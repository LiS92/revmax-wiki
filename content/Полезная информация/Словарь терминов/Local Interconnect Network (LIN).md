**Local Interconnect Network** (LIN, локальная шина обмена данными) — простая и медленная линия связи, по которой электронный блок управляет подчинёнными ему устройствами.

## Описание

Основные блоки мотоцикла обмениваются данными по быстрой [[Controller Area Network (CAN)|шине CAN]]. Для второстепенных устройств, которым не нужна высокая скорость, используется более простая шина LIN: она работает по одному проводу, и на ней всегда есть один ведущий блок, который опрашивает остальные.

По кодам неисправностей видно, что по такой шине подключены, например, фары подсветки поворота Pan America. Если связь по шине нарушается, блок записывает [[Diagnostic Trouble Code (DTC)|код неисправности]] группы U: см. [[U - Обмен данными между блоками]].
