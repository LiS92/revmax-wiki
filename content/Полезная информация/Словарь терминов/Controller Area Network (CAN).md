**Controller Area Network** (CAN, шина обмена данными) — общая линия связи, по которой электронные блоки мотоцикла обмениваются информацией.

## Описание

На мотоцикле несколько электронных блоков: [[Electronic Control Module (ECM)|блок управления двигателем]], [[Body Control Module (BCM)|блок управления электрооборудованием]], блок [[Anti-lock Braking System (ABS)|антиблокировочной системы]], [[Instrument Module (IM)|приборная панель]] и другие. Им постоянно нужны данные друг друга: например, блоку ABS — сведения о двигателе, а приборной панели — скорость, обороты и давление в шинах.

Вместо того чтобы тянуть отдельный провод для каждого сигнала, все блоки подключены к общей шине — паре проводов, по которой они по очереди передают короткие сообщения. Каждый блок «слышит» все сообщения и берёт из них нужные. Так же устроены автомобили: этот стандарт пришёл оттуда.

К шине подключён и [[Data Link Connector (DLC)|диагностический разъём]]: через него дилерский прибор [[Digital Technician II (DT II)|Digital Technician II]] связывается со всеми блоками сразу.

Если связь по шине нарушается — из-за окисленного разъёма, перетёртого провода или неисправного блока, — блоки перестают получать данные друг от друга и записывают коды группы U: [[U - Обмен данными между блоками]]. Частая причина таких проблем описана на странице [[Разъёмы под седлом и перетирание проводки]].
