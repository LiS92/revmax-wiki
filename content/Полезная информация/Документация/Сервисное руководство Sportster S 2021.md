Сервисное руководство Harley-Davidson для Sportster S 2021 модельного года (номер 94000907), на английском языке. Порядок обслуживания и ремонта, моменты затяжки, специальный инструмент, технические данные, электрические схемы.

Данные по двигателю подходят для всех трёх моделей, по раме, топливной системе и электрике — для Sportster S. Для Nightster большая часть данных совпадает; для Pan America нужно отдельное руководство.
